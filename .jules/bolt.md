## 2025-04-10 - [O(1) Dictionary initialization & Tuple `str.startswith()` Optimization]
**Learning:** Python natively supports tuples in `str.startswith()` which directly evaluates against the underlying C implementation, drastically outperforming generator expressions like `any(string.startswith(s) for s in valid_strings)`. Additionally, moving dictionary initialization outside `for` loops helps convert `O(N * B)` duplicate mapping logic into `O(N)` initial setups while cross-referencing caches natively by exploiting python dictionary mutability. Ensure dictionary parameter values reflect accurately during tests since they persist state!
**Action:** When working on batch functions with internal dictionaries referencing outer data structures, evaluate if lifting to parameter initialization and retaining internal in-place mutations reduces duplicated computing effort. Replace string checks loops using `.startswith()` and `.endswith()` taking tuples where appropriate.
